## I. Paid Tier:
### 1. **Claude Sonnet**
- Làm việc với cấu trúc thư mục phức tạp tốt
- Viết code chính xác ngay từ lần đầu, tỷ lệ sinh lỗi cú pháp cực thấp
- Tuân thủ quy trình chỉnh sữa file rất nghiêm
### 2. **Deepseek-V3**
- Thay được Sonnet, rẻ hơn 15-20 lần
- Lập trình logic tiệm cận Sonnet
- Hợp làm agent chạy hàng ngày cho tác vụ nhỏ -> trung bình
## II. Free Tier (tối ưu học và thử nghiệm):
### 1. **Gemini Flash**
- Hạn mức lớn
- Tốc độ nhanh
- Hỗ trợ Tool Calling ổn định
### 2. **Qwen Coder 32B** / **DeepSeek-V3** free của OpenRouter
- OR cung cấp endpoint free cho model open source như Qwen, Deepseek
- 32B tham số được tối ưu hoá sâu cho lập trình, rất hiểu cách viết code của agent
