# Cẩm nang Phím tắt MangoWM (Keyboard-First)

Để theo đuổi phong cách "Keyboard-First", dưới đây là bảng tổng hợp các phím tắt đã được làm sạch và tối ưu trên máy bạn. Hãy bắt đầu làm quen với từng nhóm một nhé!

## 1. Thao tác Cửa sổ Cơ bản (Window Management)
| Phím tắt | Chức năng |
| :--- | :--- |
| **`Alt + Q`** | Đóng cửa sổ hiện tại (rất thường dùng) |
| **`Super + Tab`** | Chuyển Focus qua lại giữa các cửa sổ |
| **`Alt + Điều hướng`** | Chuyển Focus sang cửa sổ Trái/Phải/Lên/Xuống |
| **`Alt + Shift + Điều hướng`** | Tráo đổi vị trí cửa sổ với cửa sổ bên cạnh |
| **`Alt + \`** | Bật/Tắt chế độ cửa sổ trôi nổi (Floating) |
| **`Alt + A`** | Phóng to cửa sổ ra toàn màn hình (Maximize) |
| **`Alt + F`** | Bật chế độ Tràn viền (Fullscreen) |
| **`Super + I`** | Thu nhỏ cửa sổ xuống thanh Taskbar (Minimize) |
| **`Super + Shift + I`** | Khôi phục cửa sổ đã thu nhỏ |
| **`Alt + Z`** | Ẩn / Hiện nhanh cửa sổ Scratchpad (Tạm cất cửa sổ) |
| **`Super + O`** | Bật / Tắt chế độ cửa sổ luôn nằm trên cùng (Overlay) |
| **`Super + G`** | Bật / Tắt chế độ dính cửa sổ trên mọi Workspace (Global) |
| **`Alt + Tab`** | Nhảy nhanh về cửa sổ vừa thao tác trước đó |

## 2. Thao tác Ứng dụng & Tiện ích
| Phím tắt | Chức năng |
| :--- | :--- |
| **`Super + Enter`** | Mở Terminal (Kitty) |
| **`Super + B`** | Mở Trình duyệt (Brave / Thorium) |
| **`Super + E`** | Mở Trình quản lý File (Yazi) |
| **`Alt + Space`** | Mở App Launcher (Tìm kiếm ứng dụng) |
| **`Super + D`** | Mở Look Launcher (Tìm kiếm chung & Web) |
| **`Super + Print`** | Chụp màn hình vùng chọn (Region) |
| **`Ctrl + Print`** | Chụp toàn bộ màn hình (All) |
| **`Super + M`** | Mở Menu Đăng xuất (Logout/Shutdown) |
| **`Super + Alt + L`** | Khóa màn hình (Lock screen) |

## 3. Không gian làm việc (Workspaces / Tags)
| Phím tắt | Chức năng |
| :--- | :--- |
| **`Super + Trái/Phải`** | Trượt sang Workspace liền kề |
| **`Ctrl + Trái/Phải`** | Nhảy đến Workspace liền kề (bỏ qua những cái trống) |
| **`Ctrl + Super + Trái/Phải`** | Đẩy cửa sổ hiện tại bay sang Workspace liền kề |
| **`Ctrl + 1 / 2 / 3`** | Nhảy nhanh tới Workspace số 1, 2, 3 |
| **`Alt + 1 / 2 / 3`** | Ném cửa sổ hiện tại sang Workspace số 1, 2, 3 |

## 4. Quản lý Màn hình đôi (Monitors)
| Phím tắt | Chức năng |
| :--- | :--- |
| **`Super + Shift + Trái/Phải`** | Đưa con trỏ chuột bay sang màn hình phụ |
| **`Super + Alt + Trái/Phải`** | Bắn cửa sổ hiện tại bay sang màn hình phụ |

## 5. Bố cục & Giao diện (Layouts & Gaps)
| Phím tắt | Chức năng |
| :--- | :--- |
| **`Super + N`** | Đổi nhanh kiểu bố cục (Tile, Grid, Scroller...) |
| **`Alt + X`** | Chuyển đổi giữa các mức tỉ lệ chia màn hình định sẵn |
| **`Alt + Shift + Enter`** | Đổi hướng chia đôi cửa sổ ngang/dọc (Layout Dwindle) |
| **`Alt + Super + Ctrl + Điều hướng`** | Xếp chồng cửa sổ lên nhau (Layout Scroller) |
| **`Alt + Shift + R`** | Bật / Tắt khe hở (Gaps) giữa các cửa sổ |
| **`Alt + Shift + X / Z`** | Tăng / Giảm độ rộng của khe hở giữa các cửa sổ |

> [!TIP]
> **Cách làm quen nhanh nhất:** Đừng cố nhớ hết! Hãy bắt đầu với Nhóm 1 (Tắt/Mở/Di chuyển cửa sổ) và Nhóm 2 (Mở App) trong vòng 2 ngày. Khi đã quen tay, hãy từ từ chuyển sang dùng phím tắt ở Nhóm 3 (Workspace) thay vì dùng chuột!
