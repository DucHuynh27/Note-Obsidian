 ### 1. Tạo dự án mới (hoặc mở dự án cũ)

  Bạn chỉ cần mở Terminal, tạo thư mục và code bình thường:
    mkdir my-project && cd my-project
  • Nếu không chỉ định gì: Dự án sẽ tự động dùng bản Node mặc định của hệ thống (v24.22.1).
  • Bạn dùng thẳng các lệnh khởi tạo quen thuộc:
    # Với React / Vite:
    pnpm create vite@latest . --template react-ts
    pnpm install
    pnpm run dev

    # Với NestJS:
    pnpm dlx @nestjs/cli new backend --package-manager pnpm

    # Với TypeScript:
    pnpm init && pnpm add -D typescript @types/node

  ──────
  ### 2. Muốn dự án dùng một bản Node cụ thể (Khác bản mặc định)

  Nếu bạn có một dự án cần chạy bản Node 22 LTS, Node 20, hoặc Node 26:

  1. Cài đặt bản Node đó (chỉ tải 1 lần, mất 2-3 giây):
    fnm install 22

  2. Khóa phiên bản vào dự án:
  Tạo file .node-version ngay trong thư mục dự án:
    echo "22" > .node-version


  👉 Xong! Nhờ tính năng --use-on-cd đã tích hợp sẵn trong zsh, mỗi lần bạn cd vào thư mục dự án đó, terminal sẽ tự động chuyển sang đúng bản Node tương
  ứng. Khi cd ra ngoài, nó tự quay về bản 24.22.1.
  ──────
  ### 3. Các lệnh fnm hữu ích bỏ túi

   Lệnh                                                                  | Công dụng
  -----------------------------------------------------------------------|-------------------------------------------------------------------------------
   node -v                                                               | Xem phiên bản Node đang chạy
   fnm list                                                              | Xem các bản Node đã tải về máy
   fnm install <version>                                                 | Tải bản Node mới (VD: fnm install 24.22.1, fnm install 26, fnm install --lts)
   fnm use <version>                                                     | Đổi tạm thời phiên bản Node trong terminal hiện tại (VD: fnm use 22)
   fnm default <version>                                                 | Đổi phiên bản Node mặc định cho toàn bộ máy

  │ Tip
  │ pnpm vẫn được quản lý toàn cục qua Nix, vì vậy ở bất kỳ bản Node nào bạn cài qua fnm, lệnh pnpm vẫn hoạt động bình thường và chia sẻ kho cache cực kỳ
  │ tiết kiệm ổ cứng.
